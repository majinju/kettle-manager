
# 系统参数

如下为本系统全部参数信息，数据对象的扩展信息（kzxx）会合并到该信息中，就是说可以通过数据对象的扩展信息修改任何允许修改的系统参数。

配置优先级：具体代码实现>数据对象中配置>前端传入>默认配置。

不是所有参数都支持前端传入，这个需要做权限控制，避免系统风险。
